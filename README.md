# CN Subtitle Hub for IINA

一个中文优先的 IINA 在线字幕聚合插件。打开电影或剧集后，在 IINA 里使用“查找在线字幕”，汇总多个来源的候选字幕，并校验片名、季集号和片源信息。

当前版本：`0.4.0`。这是 IINA 的字幕搜索插件，语音识别、内置字幕翻译和字幕自动对齐属于独立插件，不包含在本仓库中。

下载字幕后默认会保存到当前视频所在文件夹，并改成和视频同名的字幕文件，例如：

```text
Movie.Name.2021.mp4
Movie.Name.2021.srt
```

## 当前字幕源

- SubHD: 无需配置 Token，支持中文候选搜索和下载。
- 迅雷字幕: 按视频文件内容指纹查找关联字幕。
- 射手字幕: 按视频文件内容指纹查找关联字幕。
- ASSRT: 中文友好，需要你自己的 ASSRT API Token。
- SubtitleCat: 免 Token，作为冷门片 fallback，会优先抓 `zh-CN` 下载链接。
- 字幕库（Zimuku）: 已从自动搜索和插件菜单中停用；即使网站返回验证页，插件也只会跳过，不会弹出验证码输入。

默认自动搜索顺序以中文和实际匹配度为准。SubHD、迅雷、射手、SubtitleCat 都不需要任何配置；有 ASSRT Token 时再额外增加一路结果。ZIP/RAR/7z 字幕包仍会自动挑选最合适的 SRT、ASS、SSA、VTT 或 SUB。

各来源是独立的第三方服务，可用性、字幕质量和下载限制由来源决定。插件不会弹出验证码输入框，也不提供验证码绕过功能；文件指纹关联不等于已验证整部影片的字幕同步。

搜索阶段只获取候选列表，并为每个字幕源设置等待上限；真实下载地址会在选中字幕后再解析，避免逐条预检拖慢整个搜索。

## 0.4.0 季集匹配

搜索前去掉清晰度、编码、音轨和发布组等信息，例如 `Lanterns.S01E03.2160p.AMZN.WEB-DL` 使用 `Lanterns S01E03`，并补充同季合集查询。结果先校验剧名和季集，再按语言和片源信息排序；明确不同剧名、季号、集号的结果不显示。合集解压和 ASSRT 文件列表也会检查集号，不再默认挑第一个字幕。

结果显示“剧名和季集相符”“包含本集”“文件指纹匹配”等依据，不再把来源加分冒充百分比。无季集号的结果会标为待核对。无法自动判断只有中文译名、未含原名的字幕，也不能保证同集不同剪辑版的时间轴一致。

## 安装到 IINA

可直接下载仓库中的 [0.4.0 安装包](dist/cn-subtitle-hub-0.4.0.iinaplgz?raw=true)。私有仓库需要先登录有访问权限的 GitHub 账户。

运行环境为 macOS 和已启用插件系统的 IINA。项目曾在 IINA 1.5.0 上确认可加载；字幕站点后续变动可能需要更新适配。

使用 `.iinaplgz` 安装包时，打开 `IINA > 设置 > 插件`，选择安装插件并选中安装包。安装后，在 `设置 > 字幕 > 在线字幕` 中选择 `CN Subtitle Hub`，播放本地视频并使用 `字幕 > 查找在线字幕`。

从源码安装时，先安装 Node.js，进入本项目目录执行：

```sh
npm run pack
```

然后在 IINA 的插件设置里安装生成的 `cn-subtitle-hub-0.4.0.iinaplgz`。开发时也可以直接建立本地链接：

```sh
npm run link
```

然后重启 IINA，在 `设置 > 字幕 > 在线字幕` 里选择 `CN Subtitle Hub`。播放视频时使用 `字幕 > 查找在线字幕`。

字幕默认保存到影片旁边，目录需要有写入权限。同名且同扩展名的外挂字幕会被下载结果替换。

## 配置 ASSRT Token

安装后在 IINA 顶部菜单里打开：

```text
插件 > CN Subtitle Hub > 设置 ASSRT Token
```

粘贴你的 ASSRT Token。没有 Token 也能使用另外四个自动字幕源，ASSRT 会安静地跳过。

ASSRT Token 获取位置：注册并登录 ASSRT 后，在用户面板查看 API Token。

## 数据与隐私

搜索时会把清理后的片名、季集或文件内容指纹发送到相应字幕源；不会上传整部视频。ASSRT Token 由用户在 IINA 中设置，保存在本机插件偏好中，本仓库不包含账户凭证、影片或已下载字幕。
